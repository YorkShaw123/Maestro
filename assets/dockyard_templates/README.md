# 角色维护船坞

这是适用于 MUGEN 1.0／1.1 的维护手册。可以把整份目录交给 AI，也可以先让它读本页，再按任务读专题。请在 AI 对话中明确指定本目录和当前要维护的 DEF。导入文档只建立工作入口，阅读和执行任务仍由这次对话授权。

## 第一次接手

1. 读取当前工作区已有约定，核对 Git 状态、用户未提交改动、实际启动的 DEF，以及正在玩的安装副本。遇到多个可用 DEF 时列出差异，请用户确认目标。
2. 从 DEF 的 Files 段建立 CMD、CNS、扩展状态文件、AIR、SFF、SND、ACT 和公共资源清单。以引擎实际加载的档案为准，记录相对路径、文件编码和换行。
3. 用一句话写清玩家应看到的变化、保持项、成功判据。先做一条可回退的修改，再扩大覆盖范围。
4. 阅读对应专题。把已确认的 DEF、修改范围、复现步骤、测试证据和下一步补入角色已有交接记录。没有交接时，可以就地建立一份简短记录。

## 可以直接发给 AI 的第一条指令

> 请先读取船坞内的 README，再按我的任务选择专题。用实际 DEF 查清入口，列出相关状态、动画、精灵、AI 决策及其文件位置。说明一个可复现的正例和相邻反例。按照我明确授权的范围修改并验证。保留当前已有的人工操作、素材和未提交编辑。
